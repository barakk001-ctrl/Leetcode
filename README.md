# Kotlin Grind — 8-Week LeetCode Plan

Personal interview-prep tracker: 58 curated LeetCode questions across 8 weeks
(arrays/hashing, two pointers & sliding window, stack & binary search, linked
lists, trees, heap & intervals, graphs, dynamic programming), each with staged
hints, a full approach + pitfalls, and an idiomatic Kotlin solution.

Built-in spaced repetition: solved questions come back for review after 2, 7,
and 21 days. Progress, notes, and journal are stored in the browser
(localStorage) — use Export/Import in the sidebar to move progress between
devices.

## Run

Open `index.html` directly in a browser, or serve it:

```
npm start          # serves on http://localhost:3000 (or $PORT)
```

No dependencies, no build step. Question content lives in `data/week1.js`–`week8.js`.

Deep-link a question: `/#q-two-sum`.
